# ticket-comparison

A simple frontend application to look up train schedules between stations and instantly find the cheapest available ticket option. Built with raw HTML, CSS, and vanilla JavaScript.

## Features
* Filters available trains based on origin and destination input.
* Sorts the results by price automatically.
* Highlights the cheapest train route in green.
* Fully static, requiring no server or database setup.

## Project Structure
* `index.html` - Contains the form UI layout and visual CSS table styles.
* `script.js` - Contains the hardcoded train data array, search loops, and sorting logic.

## How to Run Locally
1. Download or clone this repository to your machine.
2. Open the `index.html` file directly in any modern web browser (Chrome, Firefox, Safari).

## How to Deploy on GitHub Pages
1. Create a public repository on GitHub.
2. Commit and push both `index.html` and `script.js` to your `main` branch.
3. Go to the repository **Settings** tab.
4. Click on **Pages** in the left menu.
5. Under Source, select **Deploy from a branch** and choose the `main` branch.
6. Click **Save** and wait for the live URL to generate.
